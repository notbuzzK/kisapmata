# Kisapmata
**An assistive navigation prototype focusing on the object detection**

## Features
- Uses three selectable OD models: pretrained YOLOv8, fine tuned YOLOv8, fine tuned CenterNet+MobileNet SSD Hybrid
- Feedback systems: Audio alerts, Voice Alerts, Direction commands
- Priority system: Spatial localization utilizing left/middle/center parts of the camera
- False Alert system: Minimum Confidence threshold slider reducing false alerts of the model

## Development
- SDLC: Used **Agile Delivery**
- Fine tuned models using Custom Dataset and specific hyperparameter settings
- Model benchmarking and feasibility testing **done under tight deadlines**
